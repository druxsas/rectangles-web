## Pipelines

```bash
# Poly Pizza model
cd app
node scripts/fetch-polypizza.mjs <modelId> <slug>

# Poly Haven model (gltf + bin + textures bundle)
node scripts/fetch-polyhaven.mjs <slug> [1k|2k|4k]

# Poly Haven PBR texture set
node scripts/fetch-polyhaven-tex.mjs <slug> [1k|2k|4k]

# Blender original
/Applications/Blender.app/Contents/MacOS/Blender --background \
  --python scripts/blender/<name>.py -- --out public/models/<slug>/<slug>.glb
```
